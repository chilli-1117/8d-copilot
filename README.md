# 8D Copilot · 公开演示版

8D 报告辅助生成系统 v3.1 MVP 的静态演示页面，覆盖 D1–D8 全流程、规则判断、历史库与完整报告导出。

- 在线访问：<https://chilli-1117.github.io/8d-copilot/>
- 运行模式：本地规则（不联网、不调用外部模型）
- 数据存储：仅保存在访问者自己浏览器的 localStorage 中，不上传服务器

## 说明

本仓库只发布单文件前端页面，不包含任何 API Key、服务端代码或个人数据。

原系统可选用 DeepSeek 接入；公开演示版未启用，页面右上角会显示“本地规则 · 未接 DeepSeek”。
